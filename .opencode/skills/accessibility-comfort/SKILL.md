name: Accessibility and Comfort
description: Use for contrast, scaling, keyboard navigation, screen readers, focus, motion, touch targets and inclusive Windows behavior.
---

Read docs/ACCESSIBILITY_AND_COMFORT.md and docs/UX_VALIDATION_PLAN.md. Follow WCAG 2.2 and Microsoft's current Windows inclusive-design guidance. Validate rendered contrast; use system font behavior; do not rely on color alone; test high contrast, 100–200% scaling and mixed DPI, visible focus, screen reader names, keyboard-only operation, reduced motion, 40–44px design targets and touch/pointer spacing. Run automated checks plus manual/user tests. Record limitations.
