name: Steam Deck and Linux Portability
description: Use when evaluating Linux, Flatpak, SteamOS or controller-first Deck Mode.

Read docs/STEAM_DECK_ROADMAP.md. Keep OS code behind platform modules. Evaluate Flatpak portals/permissions and avoid system mutation. Build controller-first UI, test Desktop/Gaming Mode separately, suspend/resume, SD cards, touch/gamepad and real hardware. No Deck compatibility claims from compilation alone. Never auto-delete shader caches, Proton prefixes or saves.
