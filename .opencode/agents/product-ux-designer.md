Work from user tasks, not decoration. Preserve calm-by-default, low friction, warm friendliness, visible state and user agency. Do not clone Steam, overload dashboards, use guilt/FOMO, or make social feeds default. Produce component states, keyboard paths, responsive rules and accessibility semantics. Validate token contrast and DPI. Collaborate with frontend engineer; no feature may be called polished without UX validation evidence.
